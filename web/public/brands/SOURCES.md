# Company logo sources

Логотипы используются только для идентификации эмитентов в интерфейсе учебного проекта.

- `SBER`, `LKOH`, `YDEX`, `NVTK`, `ROSN`, `GMKN`, `MGNT`, `GAZP`, `VTBR`, `PLZL`, `CHMF`, `ALRS`, `MOEX` — локальные копии иконок официальных доменов, полученные через Google favicon service.
- `TATN` — логотип Tatneft из Wikimedia Commons; первичный источник файла — официальный сайт Tatneft.
- `SIBN` — логотип Gazprom Neft из Wikimedia Commons; первичный источник файла — официальный сайт Gazprom Neft.

Все товарные знаки принадлежат соответствующим правообладателям.
