# Бюджет EventEdge

Месячный бюджет проекта — **15 000 ₽**. В Yandex Cloud действует бюджетный
контроль; при прогнозе **12 000 ₽** дальнейшее увеличение ресурсов
замораживается до ручной проверки.

Уведомления настроены на 25%, 50%, 70%, 85% и 95% бюджета.

Важно: billing budget в Yandex Cloud — это алерт, а не автоматическое отключение.
Превышение порога само по себе не остановит ресурсы.

## Технические ограничители

Деплой применяет отдельные ограничения Serverless Containers для API и worker.

Production API:

- 768 MiB RAM и 1 vCPU с гарантированной долей 20%;
- concurrency — 7 запросов на инстанс;
- 0 постоянно прогретых инстансов: после простоя первый запрос получит холодный
  старт, но плата за простаивающий API инстанс исчезает;
- autoscaling ограничен одним API-инстансом на зону;
- не более 7 одновременных API-запросов в зоне;
- timeout одного запроса — 180 секунд.

Collection worker:

- 768 MiB RAM и 1 vCPU с гарантированной долей 20% на инстанс;
- concurrency — 1: каждый timer lane получает изолированный процесс;
- 0 постоянно прогретых инстансов, autoscaling до 3;
- не более 3 одновременных worker-запросов в зоне;
- timeout одного запроса — 180 секунд;
- в production-срезе максимум памяти составил 407 MiB, CPU — 11,5%; новый
  лимит оставляет 361 MiB запаса памяти, а сниженная доля CPU может
  увеличить холодный старт и длительность тяжёлых запусков.

YDB Serverless:

- throughput cap — 500 RU/с без provisioned capacity;
- storage cap — 1 GB;
- оплачивается фактическое потребление RU, а не установленный throughput cap.

При полном autoscaling оба контура занимают не более 4 vCPU и 3 GiB RAM,
поэтому конфигурация не зависит от повышения облачных квот.

Сбор новостей также ограничен:

- не более 18 активных публичных Telegram-каналов;
- проверка Telegram — раз в 300 секунд;
- LLM вызывается только для публикаций, прошедших детерминированный фильтр
  кандидатов на сигнал. Рыночный и отраслевой контекст сохраняется без LLM-вызова.

Каноническая машиночитаемая политика лежит в
[`infra/budget-policy.yaml`](infra/budget-policy.yaml), а параметры деплоя — в
[`scripts/deploy_serverless.py`](scripts/deploy_serverless.py).

## Что не включено

Аварийное автоотключение после 15 000 ₽ не включено: оно может остановить сбор
новостей и production API. Его можно добавить отдельным триггером только после
явного решения, какие контуры отключать и как их восстанавливать.
