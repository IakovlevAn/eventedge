# EventEdge — направление UX/UI

> Code-first дизайн для внутреннего продукта. Источник истины — работающий интерфейс и его дизайн-токены, а не отдельный файл в Figma.

## Главная идея

EventEdge выглядит как профессиональный исследовательский инструмент нового поколения: быстро читается, показывает плотные данные и при этом не напоминает перегруженный торговый терминал.

Ключевой экран отвечает на три вопроса по порядку:

1. На какую акцию стоит обратить внимание?
2. Какое действие имеет смысл рассмотреть?
3. Из каких проверяемых факторов получился сигнал?

## Визуальный характер

- спокойная светлая рабочая поверхность и контрастная навигация;
- один яркий акцент вместо множества декоративных цветов;
- «вверх / нейтрально / вниз» различаются цветом, иконкой и текстом;
- табличная плотность для сканирования рынка, просторная карточка для принятия решения;
- без неона, псевдонаучных графиков, стеклянных карточек и обещаний гарантированной доходности;
- реальные продуктовые тексты и значения вместо `Lorem ipsum`.

## Design tokens

| Роль | Значение |
|---|---|
| Основной фон | тёплый серо-белый `#F3F4EF` |
| Рабочая поверхность | `#FBFCF8` |
| Навигация | графитовый `#111511` |
| Основной текст | `#171B17` |
| Положительный сигнал | зелёный `#1D7F54` |
| Нейтральный сигнал | янтарный `#A36614` |
| Отрицательный сигнал | коралловый `#B84E44` |

Шрифт — системный sans-serif. Это убирает внешнюю зависимость, ускоряет загрузку и сохраняет нативную читаемость на macOS, Windows и мобильных устройствах.

## Основные паттерны

### Рейтинг сигналов

- сортируемая и фильтруемая лента;
- тикер, направление, скор, уверенность, горизонт, цена и дневное изменение видны без перехода;
- выбор строки сразу обновляет подробную карточку;
- нейтральные сигналы показываются наравне с направленными: «ничего не делать» — полноценное решение.

### Карточка инвестиционной гипотезы

- действие сформулировано человеческим языком;
- направление и общий скор не смешиваются с уверенностью;
- вклад факторов объясняет, почему алгоритм пришёл к результату;
- исходные события и данные остаются доступными для проверки;
- условие отмены гипотезы видно рядом с действием;
- дисклеймер не перекрывает полезную информацию, но всегда присутствует.

### Административный интерфейс

- те же токены и компоненты;
- отдельные экраны источников и конфигурации модели;
- версия, статус и время последней проверки всегда видны;
- опасные изменения требуют подтверждения и оставляют аудит.

## Агентный стек

- **21st.dev MCP** — поиск готовых UI-паттернов, тем и React-компонентов;
- **shadcn/ui + Radix patterns** — доступные и предсказуемые примитивы;
- **Lucide** — единая иконографика;
- **React + Vite** — тонкий клиент без серверного рендеринга;
- собственные CSS-токены — полный контроль без привязки к визуальному конструктору.

Higgsfield MCP в продуктовый UI не входит: он предназначен для генерации изображений и видео. Его можно подключить позже только для маркетинговых материалов, если они понадобятся.

## Definition of Done для экрана

- главный сценарий понятен без инструкции;
- клавиатурный фокус видим, интерактивные элементы имеют доступные названия;
- цвет не является единственным способом передать направление;
- поддержаны desktop, узкий ноутбук и mobile;
- предусмотрены loading, empty, error и stale-data состояния;
- числа используют единый формат и не скачут при обновлении;
- интерфейс использует типы, сгенерированные из `openapi.yaml`;
- любой показатель, влияющий на решение, можно связать с источником и временем расчёта.
